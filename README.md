# 🎮 PlayStation Games Sales Analysis — Power BI

## 📊 Project Overview

An interactive Power BI dashboard developed to analyze PlayStation
game sales data and identify trends across games, platforms, genres,
and sales performance.

## 🎯 Objectives

- Analyze overall game sales performance
- Identify top-performing games
- Compare sales across PlayStation platforms
- Analyze genre-wise sales performance
- Identify trends and patterns in game sales
- Build interactive business visualizations

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Transformation
- Data Visualization

## 🔍 Key Analysis

The dashboard provides insights into:

- Overall game sales
- Platform-wise performance
- Genre-wise performance
- Top-selling games
- Sales trends
- Game-level performance
