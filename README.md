# 🎮 PlayStation Games Sales Analysis — Power BI

## 📊 Project Overview

An interactive Power BI dashboard developed to analyze PlayStation game sales data and identify trends across games, platforms, genres, and sales performance.

The project focuses on transforming raw sales data into meaningful business insights through data cleaning, analysis, KPI creation, and interactive visualizations.

---

## 🎯 Project Objectives

- Analyze overall PlayStation game sales performance
- Identify the top-performing games
- Compare sales performance across different platforms
- Analyze sales trends over time
- Understand genre-wise game performance
- Identify patterns in game sales
- Build an interactive dashboard for business-oriented analysis

---

## 🛠️ Tools & Technologies

- **Power BI**
- **Power Query**
- **DAX**
- **Data Cleaning & Transformation**
- **Data Modeling**
- **Data Visualization**

---

## 📁 Dataset

The project uses a synthetic PlayStation game sales dataset created specifically for this portfolio project.

The dataset contains information related to PlayStation games and their sales performance across different dimensions.

### Key Data Attributes

- Game Title
- Platform
- Genre
- Release/Sales Year
- Regional Sales
- Global Sales

> **Note:** The dataset is synthetic and was created for learning, analysis, and portfolio demonstration purposes.

---

## 🔍 Key Analysis

The dashboard includes analysis such as:

### 🎮 Game Performance
- Identification of top-selling games
- Comparison of game-level sales performance
- Analysis of high-performing titles

### 🕹️ Platform Analysis
- Comparison of sales across PlayStation platforms
- Identification of stronger-performing platforms
- Platform-level sales trends

### 🎭 Genre Analysis
- Comparison of sales across different game genres
- Identification of popular and high-performing genres

### 📅 Sales Trends
- Analysis of sales performance over time
- Identification of changes and trends in game sales

### 📊 Interactive Filtering
The dashboard allows users to interactively filter the analysis based on available dimensions and explore different segments of the dataset.
